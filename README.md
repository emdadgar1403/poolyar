# 🪙 پولیار نوجوان (Poulyar Nojavan)

> **اپلیکیشن هوشمند مدیریت پول توجیبی، پس‌انداز و رفتارهای مالی نوجوانان**  
> توسعه‌یافته با **Kotlin**، **Jetpack Compose (Material 3)** و **Room Database** به‌صورت کاملاً آفلاین و با پشتیبانی ۱۰۰٪ از رابط راست‌به‌چپ (RTL) و اعداد و مبالغ به زبان فارسی (تومان).

---

## 📖 درباره برنامه

**«پولیار نوجوان»** یک همراه مالی هوشمند، جذاب و آموزشی برای نوجوانان (به‌ویژه رده سنی ۱۰ تا ۱۶ سال) است که به آن‌ها کمک می‌کند تا از سنین پایه:
* ارزش پول توجیبی و برنامه‌ریزی برای خرج‌کردن را یاد بگیرند.
* بخشی از پول خود را برای اهداف بزرگ‌تر در **قلک پس‌انداز** ذخیره کنند.
* خواسته‌ها و آرزوهای خود را به **اهداف مالی زمان‌بندی‌شده** تبدیل نمایند.
* والدین بتوانند با **تنظیمات رمزداری‌شده (PIN)**، بودجه هفتگی، روز پرداخت و سقف هزینه را به‌آسانی مدیریت کنند.

---

## ✨ قابلیت‌های کلیدی

### ۱. داشبورد مالی نوجوان (Dashboard)
- **کارت وضعیت دارایی:** نمایش «موجودی قابل خرج»، «موجودی قلک پس‌انداز» و «مجموع کل دارایی».
- **کارت بزرگ پول توجیبی هفتگی:** نمایش مبلغ مشخص‌شده (مثلاً ۳۵۰٬۰۰۰ تومان) همراه با وضعیت واریز این هفته (`پرداخت شده ✓` یا `در انتظار پرداخت`) و دکمه تک‌لمسی ثبت دریافت.
- **بخش «این هفته چطور خرج کردم؟»:** نمودار دونات Canvas متحرک و جدول تفکیک هزینه‌ها به همراه درصد سهم هر دسته.
- **دکمه‌های اقدام سریع:** ثبت سریع هزینه، ثبت دریافت پول توجیبی، انتقال به قلک پس‌انداز و تعریف هدف مالی جدید.
- **فهرست آخرین تراکنش‌ها:** با برچسب‌های رنگی و امکان مدیریت و حذف.

### ۲. ثبت و مدیریت پول توجیبی هفتگی
- تقویم مستقل هفتگی منطبق بر تقویم شمسی (شنبه تا جمعه).
- نمایش تاریخچه هفته‌ها:
  - هفته اول: ۳۵۰٬۰۰۰ تومان
  - هفته دوم: ۳۵۰٬۰۰۰ تومان
  - هفته سوم: ۳۵۰٬۰۰۰ تومان
- محاسبه مجموع پول توجیبی پرداخت‌شده در ماه و سال.
- قابلیت ویرایش مبالغ روزانه و هفتگی توسط والدین (بدون مقادیر هاردکدشده).

### ۳. ثبت هوشمند هزینه‌ها
- ثبت مبلغ، عنوان، تاریخ شمسی، توضیحات اختیاری و دسته‌بندی با آیکون‌های اختصاصی:
  - 🍔 **خوراکی:** خوراکی‌های مدرسه، آبمیوه، میان‌وعده
  - 🎮 **تفریح:** بازی، شهربازی، تفریح با دوستان
  - 📚 **کتاب و آموزش:** کتاب داستان، لوازم‌التحریر، کلاس
  - 🧸 **وسایل شخصی:** پوشاک، وسایل اتاق، اکسسوری
  - 🎁 **هدیه:** کادو برای خانواده و دوستان
  - 🚕 **رفت‌وآمد:** کرایه تاکسی، اتوبوس، اسنپ
  - 💰 **سایر:** مخارج متفرقه
- کسر خودکار و آنی از موجودی قابل خرج نوجوان.

### ۴. قلک پس‌انداز (Savings)
- امکان انتقال بخشی از موجودی به قلک پس‌انداز (مثلاً از ۲۰۰٬۰۰۰ تومان موجودی، ۵۰٬۰۰۰ تومان به قلک منتقل شده و موجودی قابل خرج ۱۵۰٬۰۰۰ تومان می‌شود).
- امکان برداشت مجدد از پس‌انداز به موجودی در صورت نیاز.
- نمایش درصد پس‌انداز در مقایسه با نرخ هدف پیشنهادی والدین.

### ۵. بخش اهداف مالی من («هدف‌های من»)
- تعریف اهداف خرید موردعلاقه (مانند هدفون گیمینگ، دوچرخه، کفش ورزشی و ...).
- تعیین قیمت هدف و تخصیص پس‌انداز.
- نوار پیشرفت متحرک (Progress Bar) همراه با درصد تحقق.
- جشن تصویری و برچسب `تکمیل شده! 🎉` هنگام رسیدن پس‌انداز به مبلغ هدف.

### ۶. گزارش‌های تحلیلی و نمودارها
- **گزارش هفتگی:** تفکیک پول توجیبی، مجموع هزینه‌ها، پس‌انداز این هفته، مانده موجودی و نمودار توزیع دسته‌بندی‌ها.
- **گزارش ماهانه و سالانه:** مجموع پول توجیبی‌های دریافتی امسال، مجموع هزینه‌ها، پس‌انداز کل، پرخرج‌ترین دسته‌بندی و میانگین هزینه روزانه نوجوان.

### ۷. هشدار دوستانه سقف هزینه
- قابلیت تعیین سقف هزینه هفتگی در تنظیمات والدین.
- در صورت عبور هزینه‌ها از سقف، نمایش هشدار دوستانه، محترمانه و مشوق هوش مالی:
  > *«هزینه‌های این هفته از بودجه تعیین‌شده بیشتر شده است. بیا با هم هوشمندانه‌تر مدیریت کنیم! 💡»*

### ۸. بخش امن والدین (Parent Gate)
- محافظت از تنظیمات اصلی با رمز عبور ۴ رقمی (PIN پیش‌فرض: `۱۲۳۴`).
- تنظیم مبلغ پول توجیبی روزانه و هفتگی.
- تعیین روز واریز پول توجیبی (مثلاً شنبه).
- تغییر سقف هزینه و درصد پیشنهادی پس‌انداز.
- امکان تغییر رمز عبور PIN در هر زمان.
- دکمه بازیابی داده‌های نمونه اولیه یا پاکسازی کامل اطلاعات.

### ۹. سیستم اعلان محلی (Offline Notifications)
- یادآوری دریافت پول توجیبی در روز مشخص‌شده بدون نیاز به اتصال اینترنت.
- امکان فعال یا غیرفعال کردن اعلان‌ها و دکمه تست ارسال اعلان در بخش تنظیمات.

## 🏗️ معماری و فناوری‌ها

| مؤلفه | فناوری استفاده‌شده |
| :--- | :--- |
| **زبان** | ۱۰۰٪ [Kotlin](https://kotlinlang.org/) |
| **رابط کاربری (UI)** | [Jetpack Compose](https://developer.android.com/jetpack/compose) + [Material Design 3](https://m3.material.io/) |
| **معماری نرم‌افزار** | MVVM (Model-View-ViewModel) + Repository Pattern |
| **پایگاه‌داده محلی** | [Room Database](https://developer.android.com/training/data-storage/room) همراه با KSP |
| **مدیریت همزمانی** | Kotlin Coroutines & `StateFlow` واکنشی |
| **چینش و زبان** | کاملاً راست‌به‌چپ (RTL)، تقویم شمسی جلالی و فونت‌های فارسی |
| **اعلان‌ها** | Android `NotificationChannel` و `NotificationManagerCompat` |
| **تست‌ها** | Robolectric و JUnit برای تست‌های محلی JVM |

## 🚀 راهنمای نصب، اجرا و خروجی APK

### پیش‌نیازها
* **Android Studio** نسخه Ladybug (2024.2.1) یا جدیدتر
* **JDK 17** یا بالاتر
* حداقل نسخه اندروید دستگاه: **Android 8.0 (API 26)** به بالا

### ۱. باز کردن پروژه
1. این مخزن را Clone کنید یا فایل‌های آن را دانلود نمایید:
   ```bash
   git clone https://github.com/your-username/poulyar-nojavan.git
   ```
2. نرم‌افزار **Android Studio** را باز کرده و گزینه **Open** را انتخاب کنید.
3. پوشه ریشه پروژه را انتخاب کرده و منتظر اتمام عملیات **Gradle Sync** بمانید.

### ۲. اجرای پروژه
- یک شبیه‌ساز (Emulator) یا دستگاه اندرویدی متصل را انتخاب کرده و دکمه **Run (Shift + F10)** را فشار دهید.

### ۳. ساخت و دریافت فایل خروجی APK (نسخه Debug)
فایل آماده APK کامپایل‌شده در پوشه زیر در ریشه پروژه قرار دارد:
```
build_app/poulyar-nojavan.apk
```

همچنین در صورت نیاز به بیلد مجدد از منوی بالای اندروید استودیو:
  ```
  Build > Build Bundle(s) / APK(s) > Build APK(s)
  ```
- پس از اتمام، فایل در مسیر زیر در دسترس خواهد بود:
  ```
  app/build/outputs/apk/debug/app-debug.apk
  ```

### ۴. ساخت خروجی نهایی برای انتشار (Release APK)
1. از منوی اصلی مسیر زیر را انتخاب کنید:
   ```
   Build > Generate Signed Bundle / APK
   ```
2. گزینه **APK** را انتخاب کرده و دکمه **Next** را بزنید.
3. کلید اختصاصی امضا (Keystore) خود را مشخص نمایید.
4. حالت ساخت را روی **release** قرار داده و دکمه **Create** را بزنید.
5. یا از طریق خط فرمان ترمینال:
   ```bash
   ./gradlew assembleRelease
   ```

## 🔒 حریم خصوصی و امنیت داده‌ها

- **۱۰۰٪ محلی و آفلاین:** تمام اطلاعات مالی، مبالغ، تراکنش‌ها و اهداف تنها بر روی حافظه داخلی دستگاه شما (SQLite/Room) نگهداری می‌شوند.
- **بدون اینترنت:** برنامه برای عملکرد اصلی هیچ‌گونه وابستگی به اینترنت یا سرور ابری ندارد و هیچ داده‌ای از دستگاه خارج نمی‌شود.
- **حفاظت از تنظیمات:** والدین می‌توانند با خیال راحت دستگاه را در اختیار فرزند خود قرار دهند، زیرا تغییر سقف‌ها و مبالغ بودجه مستلزم وارد کردن PIN است.
